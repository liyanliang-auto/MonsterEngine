## 3DGS Vulkan Splat Pass — 空白窗口根因定位与修复

**分支**: `feature_3dgs_vulkan_splat_pass`

### 根因（已确认）
`SplatPipeline::ensureSortPassesInitialized()` 在 readback 处调用了
`cmdList->end(); m_device->waitForIdle();`
但 `VulkanDevice::waitForIdle()` 只调用 `vkDeviceWaitIdle`，**不会提交 command buffer**。
→ GPU 从未执行 preprocess/prefixSum 的 copyBuffer + readback
→ `m_realSortElements` 读回的是垃圾值（通常 0/1），被 clamp 到 1
→ 后续 sort/render pass 只处理 ~1 个 gaussian → 窗口全灰（仅背景色）。

### 修复
新增 `IRHICommandList::submitAndWait()`（虚方法，空实现）+ Vulkan 覆写实现：
- 用 command buffer **自身的 fence** 提交（`submitActiveCmdBufferWithFence(..., fence)`）
- `vkWaitForFences(..., UINT64_MAX)` 等待完成
- 理由：用新 fence 会导致 `prepareForNewActiveCommandBuffer()` 死锁（它等的是 CB 自己的 fence）
`SplatPipeline.cpp` 把 `waitForIdle()` 替换为 `submitAndWait()` + readback 日志。

### 增加的英文诊断日志（用户要求）
- `SplatPipeline.cpp`: readback 提交前后 + `exclusiveSum/lastTiles -> totalSortElements`；Begin frame 打印 `totalSortElements/gaussianCount`
- `SplatPass.cpp`: Preprocess dispatch 前打印 pipeline/DS 有效性 + groupCount + near/far/culling；`updateCamera` 打印 camPos
- `SplatSceneApplication.cpp`: `buildCameraUniforms` 打印 camPos/focal/tanFov/image/shDegree
- `SplatPLYLoader.cpp`: load 循环累加 model bbox min/max/center/extent 并打印
